# 从结果差异到可检验的组合方法

## 1. 先判断已有材料能支持什么

| 可用证据 | 可以推进 | 尚不能得出 |
| --- | --- | --- |
| 实验总分、配置 | 排查协议差异，提出候选解释 | 哪些样本被改善、哪些内部关系是原因 |
| 配对预测/分数、标签 | 纠错与新增错误、类条件差异、融合候选 | 内部特征依赖机制 |
| 配对中间表示 | 关系描述、探针、干预设计 | 仅凭相关性证明有利 |
| 可重放 checkpoint 与推理协议 | 当前模型内受控干预、固定权重搜索 | 重训练新结构一定改善 |
| 独立训练重复及适当复核数据 | 检验跨训练随机性或条件的稳定性 | 超出已验证分布的普遍结论 |

允许在材料有限时做有边界的工作，不把所有材料列为必须向用户索取的清单。没有配对样本就不计算配对变化。只有输出分数时，研究分数与错误互补，不能假装观察过隐藏特征。

先写可证伪的问题，例如：“A 的增益是否与两路的局部时间对应有关？在同一 A checkpoint 内，选择性削弱这一对应是否比匹配对照更伤害分类？用无标签的确定性操作增强对应能否改善完整开发集表现？”

## 2. 从差异生成假设

对相同样本比较基线与候选：都对、仅基线对、仅候选对、都错。分类以外任务采用逐样本损失或适当的查询/组级差值。优势子集仅用于提出假设，筛选和评估回到完整开发集。

可选描述量要与信号轴、模型及假设相符：

| 假设对象 | 描述量示例 | 首先排查 |
| --- | --- | --- |
| 路间共性与差异 | 共模/残差能量比、协方差、余弦相似度、低秩谱 | 大幅值、归一化、特征维度造成的表象 |
| 时间或空间对应 | 局部交叉相关、延迟、相关长度、平滑度 | 轴语义、边界填充、标签/时序泄漏 |
| 频谱或尺度分工 | 带内功率、谱重心、跨路相干性 | 池化混叠、非线性、采样率、尺度差异 |
| 局部显著性 | 幅值包络、峰度、局部能量比 | 放大噪声、只在极少样本出现 |
| 预测互补 | 错误重叠、分数间距、分歧、校准误差 | 分数不可比、分布差异、不可实现的 oracle |

不同卷积感受野不自动等于确定的物理频带；隐藏时间轴上的谱也不直接等于原信号的物理频谱。余弦相似度高的共同部分可能含类别信号，不能默认都应抑制。

跨独立训练模型的坐标存在置换、旋转和尺度自由度。不要直接替换同编号通道，或根据参数距离判断增益来自上游还是下游。需要对齐时，只在允许的开发数据上估计映射，记录其拟合成本与残留误差；优先在各自模型内干预，比较对相同因素的响应。

## 3. 可选的类别可分性筛选

先使用简单基线描述，再比较“基线 + 候选关系”。视问题增加同维随机特征、参数量匹配和标签置乱对照。标准化、特征选择、映射和探针拟合均放在训练折内；按被试、会话、序列或原始样本分组，避免相邻窗口或同源增强跨折泄漏。

胜过随机增广不等于胜过基础描述。所有关系增广都失败时，应如实保留这一结果，仍可基于其他假设做干预，但不能声称探针发现额外类别信息。一个探针的负结果也不证明所有读出器都无法使用该信息。

探针预测分数不一定是概率；NLL 等概率指标需要合法概率或折内校准。可逆确定性变换不凭空增加信息；它可能改变有限容量读出器使用信息的难度。全维正交变换配各向同性线性读出可能等价，实验前检查这些不变性。

## 4. 干预卡与对照

每个候选至少定义：

```text
假设与反证：希望解释哪种差异？什么结果会削弱它？
对象：模型、插入点、张量轴/分数语义、所需上下文。
算子：z' = T_alpha(z; s)，s 在推理时如何得到？
恒等：T_0(z) = z，或另有明确恒等参数。
目标：预期增加/减少的统计量及其实际测量方式。
保持量与副作用：能量、幅度谱、相位、边际分布、尺度、时序等。
破坏/增强/对照：参数范围、匹配方式、随机种子、恢复实验。
评价：主指标、参考基线、统计单位、开销及淘汰条件。
```

选择能排除具体混淆的对照，不机械要求每类实验全做：

- **恒等与重放**：输出、预测和状态应符合预设数值容差；完全撤销操作主要验证实现。
- **选择性破坏**：改变目标关系，同时尽可能保持非目标统计量。记录哪些量没有保持，避免把普通分布外损伤当作机制证据。
- **匹配干预**：随机位置/方向、共同变换或非目标成分等，视假设选择。参数相同不代表实际扰动范数相同；测量真实幅度及边际分布，不宣称未经验证的匹配。
- **部分恢复**：只恢复目标因素，保留其他扰动，用于区分目标作用与一般损伤。
- **双向与剂量**：增强、减弱和零强度的适度范围；观察响应方向和稳定区间，不只记录最优点。
- **操作有效性**：从插入点检查到下游。若增益被归一化抵消、整体 logit 正比例缩放不改 argmax，停止把该参数当作准确率改进方向。

先测目标统计量是否真的改变，再测模型输出与任务指标。非零交互仅说明有交互，不说明交互有利；平均 logits 的等价不保证平均准确率或 NLL 等非线性指标等价。

## 5. 候选算子是模板，不是有效性承诺

以下参数只可在约定数据上选择，所有操作需有恒等状态、合法形状和部署可得输入：

- 共性/差异：`c = mean_i(z_i)`，`r_i = z_i - c`，`z_i' = a*c + b*r_i`。检查统一缩放不变性，避免把尺度变化误称关系增强。
- 重复分量：`z_i' = z_i - lambda * P(z_i)`；投影方向的来源及估计数据须明确，使用零范数保护，并检验共享成分是否含有用信号。
- 频谱重分配：`z' = inverse_FFT(g(omega) * FFT(z))`；仅对有意义的轴操作，保持实值约束、边界及可用时间范围。
- 局部幅值：`z' = z * (1 + alpha * q(z))`；`q` 采用有界、无真值依赖的局部统计，检查噪声和异常值放大。
- 对齐/交互：有限延迟、局部对比、归一化差异、逐元素乘积或协方差关系；说明形状变化以及原下游是否可接受。
- 输出组合：概率混合、logit 混合、秩融合或可部署门控；先核对类别/候选集合与分数语义，权重和阈值只在开发数据上定。

冻结模型时维度通常须兼容；若降维后还要接回原下游，必须说明适配器如何定义、是否需要拟合、是否改变参数。不能把加入并训练新适配器默认为固定权重实验。

## 6. 真正检验组合

多个单项有效不代表组合有效；错误互补或 oracle 正确率并集也不提供可部署选择规则。在用户授权组合搜索时，使用同一协议与统计口径比较：

| 实验 | 所回答的问题 |
| --- | --- |
| 基线、A、B | 单项收益各是多少？ |
| A+B | 组合是否优于基线及最强单项？ |
| A 后 B、B 后 A | 非交换算子是否存在顺序效应？ |
| 组合去掉一项 | 该项在其他项存在时还有多少贡献？ |
| 合适的容量/计算/校准预算对照 | 收益是否仅来自多一次计算或更多选参？ |

以“越高越好”的同一指标 `m` 计算：`gain(B|A) = m(A+B)-m(A)`；交互差 `I = m(A+B)-m(A)-m(B)+m(base)` 只是该指标尺度上的描述量，不是因果证明。还需查看逐样本纠错重叠、互相抵消以及受益群体。

先规定组合数量、顺序和权重搜索预算，避免所有组合穷举。不能按每个样本的真实正确性择优；输入自适应门控则需要可执行规则及单独的开发验证。相同公式的多个参数不算多个机制，组合也不自动算一个独立机制发现。

## 7. 从证据反推结构

用“观察 → 干预及对照 → 受益范围 → 数学表达 → 训练后待验证预测”组织每项建议。明确哪些部分是数据观察，哪些是解释，哪些是未来结构假设。

固定下游只能检验当前权重是否能利用某变化。干预失败不能单独排除未来重训练后的价值，干预成功也不保证重训练有效。若需要把上游表示与下游适配的影响分开，可另行提出冻结表示、使用同等读出器训练预算的交叉设计；只有用户授权该训练阶段后才实施。
